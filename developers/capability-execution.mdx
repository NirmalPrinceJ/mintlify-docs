# Capability & Execution

A capability defines what the system can do. The Execution Fabric defines how it is performed.

```text
Work Need
 ↓
Capability
 ↓
Governance
 ↓
API / MCP / Tool / Workflow / Agent
 ↓
Source System
 ↓
Receipt
 ↓
Reconciliation
```

Provider implementations remain behind stable platform contracts.
