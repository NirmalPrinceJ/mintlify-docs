# Spine Schema

The Spine Schema is the canonical semantic model for organizational context.

Core concepts include Organization, Person, Team, Role, Domain, Goal, Objective, Work, Entity, Relationship, Event, Decision, Communication, Evidence, Policy, Capability, Agent, System and Outcome.

Provider schemas are normalized and semantically synthesized into this model; they do not redefine the canonical ontology.
