This page tracks notable changes to IntegrateWise. The format follows [Keep a Changelog](https://keepachangelog.com/).

<Update label="0.4.0" description="2026-04-10">
  **India and Dubai market connectors, billing fixes, and real sync in the loader.**

  ### Added — India/Dubai market connectors

  - **Google Sheets** — full Sheets API v4 + Drive API v3 with OAuth.
  - **Tally ERP/Prime** — XML HTTP API for Indian accounting (port 9000).
  - **Razorpay** — REST API for Indian payment processing (payments, settlements, customers, disputes).
  - **Vyapar** — REST API for Indian SMB invoicing and inventory.
  - **Khatabook** — REST API for Indian SMB bookkeeping (ledger, transactions, parties).
  - **Shiprocket** — Token-based auth for Indian e-commerce logistics (orders, shipments, tracking).
  - Sync adapter count: 46 → 52 providers.

  ### Fixed — Billing system (7 disconnections resolved)

  - Plan IDs unified: backend now matches frontend (`free` / `starter` $29 / `growth` $79 / `enterprise` custom).
  - Dual-schema entitlement read: `/v1/entitlements/:tenantId` reads Schema A + Schema B with fallback.
  - `SubscriptionsPage` mounted on the `billing` route across all 12 domain content maps.
  - `SubscriptionsPage` rewritten with real `TenantContext` data, `BillingClient` invoice fetching, and Stripe checkout.
  - `TenantProvider` mounted in `AppShell` wrapping the workspace stage (was missing from the component tree).
  - Free subscription auto-created on onboarding completion.
  - `UpgradePrompt` fixed: uses `useNavigate()` instead of a dead `/upgrade` link.

  ### Changed — Loader service

  - `processCreamyLayer()` and `processBackgroundSync()` now call real `universalSync()` instead of generating mock data.
  - Graceful fallback to placeholder records if a provider is not in `SYNC_REGISTRY`.
</Update>

<Update label="0.3.0" description="2026-04-10">

</Update>
