# MCP Registry

MCP expands interoperability with tools and resources.

```text
Capability
 ↓
Governance
 ↓
Approved MCP Server
 ↓
Tool / Resource
 ↓
Result
 ↓
Normalization / Reconciliation
```

MCP availability does not create permission, authority or canonical truth.
