# Integration Discovery

Integration Discovery determines which external systems and capabilities are available to a tenant, user, host and current Work.

```text
Host + User + Role + Domain + Work
 ↓
Discovery
 ↓
Available Integrations
 ↓
Compatibility / Security / Policy
 ↓
Connect → Authorize → Activate
```

Discovered, connected, authorized and active are distinct states.
