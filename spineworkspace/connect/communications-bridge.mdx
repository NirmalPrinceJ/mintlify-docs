# Communications over the Bridge

The Communications Bridge carries Work-linked communication and contextual references between the Human Workbench, Twin, agents and connected channels.

```text
Human / Twin / Agent
 ↓
Communications Bridge
 ↓
Work + Context Reference
 ↓
Slack / Email / Chat / Meetings / Agent Communication
```

## Boundary

The Bridge is not canonical memory and does not create authority. Communication-derived evidence can enter the governed context and memory lifecycle.
