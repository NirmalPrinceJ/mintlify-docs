# Agentic Workbench

The Agentic Workbench is the operating environment of the user's bounded Twin.

## Responsibilities

- Understand current Work
- Assemble operational context
- Observe / Orient / Decide / Act
- Allocate Work
- Delegate to agents
- Invoke capabilities
- Coordinate communications
- Monitor execution
- Verify and reconcile outcomes
- Report to the user

## Boundary

The Twin operates on bounded AI Operational Sandbox context. It does not directly read or write canonical Spine.
